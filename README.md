# Portfolio

Personal portfolio built with Astro + Tailwind CSS. Config-driven: personal info and
feature flags live in `src/site.config.ts`; projects, experience and achievements are
content collections under `src/content/`.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # output in dist/
npm run preview
```

See `CLAUDE.md` for design rules and architecture.
